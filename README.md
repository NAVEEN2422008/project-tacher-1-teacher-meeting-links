# Teacher-1 — Teacher Meeting Links

A static HTML page that lists a teacher's online class meeting links (Zoom) with a background logo.

## Features

- Links to Social, Maths, and Chemistry Zoom meetings
- Styled hyperlinks (hover/visited/active colors)
- School logo used as a fixed page background

## Tech Stack

- HTML, inline CSS

## Project Structure

```
tacher-1/
├── link.html   # the meeting-links page
└── logo.jpg    # background logo image
```

## Usage

Open `link.html` in any browser (or host it on any static server):

```bash
python3 -m http.server 8000
```
